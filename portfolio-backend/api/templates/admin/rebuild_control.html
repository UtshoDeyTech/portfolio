💡 The rebuild runs in the background. Check back in a minute to see your changes live.

ℹ️ When to Rebuild

  • After adding new blogs: New posts need to be built into static pages
  • After updating content: Changes to existing posts or data
  • After changing settings: Home page data, featured posts, etc.
  • Automatic rebuilds: The system also rebuilds every 6 hours automatically

💡 Tips

  • Wait before refreshing: The rebuild process takes 30-60 seconds to complete
  • Check the logs: Rebuild logs are available at /home/ubuntu/portfolio/auto-rebuild.log
  • Clear browser cache: Use Ctrl+Shift+R (or Cmd+Shift+R on Mac) to force refresh
  • No need to rebuild often: Only rebuild when you want changes to go live
